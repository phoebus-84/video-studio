# Poetry short — contract example, version 1.0.0

This is synthetic test data, not an approved production format or reference.
No compiler is registered for this example yet.

## Standard

Native vertical output. Georgia text, captions@1.1.0 and narrator-v1 are
fixed by the schema; content, pictures and voice cues depend on the episode.
Do not redesign these standards while filling an episode. A requested change
needs a new immutable template version and a documented reason here.

## Procedure

Instantiate the pinned draft, fill every __FILL__ value (holdSeconds must
be a number), validate, acquire/verify assets and narration, resolve measured
cues, compile and review the layout sheet, render, audit and seek explicit
human approval. Do not invent approval or silently use another voice/profile.
Compiler and series QA integration are separate from these contract fixtures.
