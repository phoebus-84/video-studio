# Word Timing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the provider-neutral `WordTiming` contract — when each word of one audio take is spoken — with a shared validator, a `lineSpan` helper, generated bindings and fixtures converted from two real CreativeStudio takes.

**Architecture:** A new kind in `studio/contracts/schemas/v1alpha1/` owns the record shape. `studio/contracts/src/word-timing.mjs` compiles it with Ajv and adds the rules a schema cannot express (order, ranges, text agreement, audio hash), returning every problem as `{ code, message, path }` exactly like `validateEditTimeline`, whose `jsonPath` it reuses. Fixtures are produced once by a throwaway conversion script from `../CreativeStudio` (read-only); invalid fixtures are a valid base plus a one-line JSON patch, checked by a new `check:schemas` script.

**Tech Stack:** Node 22 ESM, JSON Schema 2020-12 (`prefixItems` tuples), Ajv 8 strict, `node:test`, the repo's bindings generator.

**Spec:** `docs/superpowers/specs/2026-10-05-word-timing-design.md`

## Global Constraints

- `apiVersion` is `studio.video/v1alpha1`, `kind` is `WordTiming`; `$id` is exactly `https://video.studio/schemas/v1alpha1/word-timing.schema.json`.
- Times are **seconds of the take's own audio** (numbers ≥ 0), never frames.
- `ContentHash` is `^sha256:[a-f0-9]{64}$`.
- Problem codes are exactly: `schema`, `audio-mismatch`, `word-order`, `out-of-range`, `text-mismatch`, `bad-line`, `speech-order`, `energy-length`.
- Tolerances are named exported constants: `WORD_OVERLAP_TOLERANCE_SECONDS = 0.001`, `DURATION_TOLERANCE_SECONDS = 0.05`, `ENERGY_LENGTH_TOLERANCE_SAMPLES = 1`.
- Words carry the written token; `spoken` only where the pronunciation differs. Nothing in this contract names a TTS provider as required.
- `../CreativeStudio` is read-only. The conversion script is not committed; its output fixtures are.
- `@studio/contracts` goes from `0.2.0` to `0.3.0` (new kind: additive).
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

- Text with irregular whitespace (double spaces, newlines between verses) must still match its words — pinned in Task 2 ("compares text ignoring whitespace runs, not punctuation").
- A word dropped at the very end of a take (a truncated alignment) must be caught, not only a changed word in the middle — pinned in Task 2 ("notices a word missing at the end").
- Aligner rounding at the 1 ms / 50 ms boundaries must pass, just beyond must fail — pinned in Task 2 ("tolerates aligner rounding, but not more").
- `audioHash` omitted (caller has no file) must not be treated as a mismatch — pinned in Task 2 ("rejects timing made for another take").
- A take without lines asked for `lineSpan` must throw, not return garbage — pinned in Task 2 ("refuses a line that does not exist").

```js
// Reads ../CreativeStudio (read-only); writes studio/contracts/fixtures/word-timing/valid/.
// Usage (from studio/contracts): node <this file> <path to CreativeStudio> <output dir>
import { readFileSync, writeFileSync, mkdirSync } from "node:fs";
import { resolve } from "node:path";

const [cs, out] = process.argv.slice(2);
if (!cs || !out) throw new Error("usage: convert-cs-timing.mjs <CreativeStudio dir> <output dir>");
const read = (rel) => JSON.parse(readFileSync(resolve(cs, rel), "utf-8"));
const write = (name, doc) => {
  mkdirSync(out, { recursive: true });
  writeFileSync(resolve(out, name), JSON.stringify(doc, null, 2) + "\n");
};

// ── Il lampo long, block "epoca": an ElevenLabs block take ──────────────────
{
  const base = "productions/poesie-museo-long/il-lampo-long";
  const words = read(`${base}/generated/timing/takes/epoca/words.json`);
  const energy = read(`${base}/generated/timing/takes/epoca/energy.json`);
  const input = read(`${base}/generated/timing/takes/epoca/input.json`);
  const line = read(`${base}/production.json`).lines.find((l) => l.id === "epoca");
  const written = line.text.split(/\s+/);
  const spoken = line.tts_text.split(/\s+/);
  if (written.length !== words.length || spoken.length !== words.length) throw new Error("epoca: token counts differ");
  write("epoca-take.json", {
    apiVersion: "studio.video/v1alpha1",
    kind: "WordTiming",
    take: { id: "epoca" },
    // Hash recorded by CreativeStudio and re-checked against the file; duration measured with ffprobe.
    audio: { path: "assets/takes/epoca.mp3", hash: `sha256:${input.sha256}`, durationSeconds: 47.833 },
    text: line.text,
    spokenText: line.tts_text,
    language: "it",
    alignment: { provider: "elevenlabs", model: "forced-alignment", method: "forced", createdAt: "2026-10-04T00:00:00Z" },
    words: words.map((w, i) => ({
      text: w.text,
      ...(spoken[i] !== written[i] ? { spoken: spoken[i] } : {}),
      start: w.start,
      end: w.end,
    })),
    energy: { rate: 30, values: energy },
    metadata: { source: `CreativeStudio ${base}, take epoca` },
  });
}

// ── San Martino: a whole recital with lines and speech spans ───────────────
{
  const base = "productions/poesie-fonti/02-san-martino/generated/timing";
```

```js
// ---------------------------------------------------------------------------
// Word timing per take
// ---------------------------------------------------------------------------
// When each word of one audio take is spoken, in seconds of that audio. The
// take may come from any TTS (the local Qwen worker, ElevenLabs) or a
// recording, and the timing from any aligner (forced alignment, whisper):
// the contract records which, but depends on neither.
//
// Words carry the WRITTEN token — what is on screen, what a cue names — and
// `spoken` only where the pronunciation differs ("Myricae." / "Mirìce.").
// Lines are ranges of words, so their text and times cannot disagree with
// the words. The audio hash binds the timing to one exact file: timing made
// for another take is rejected when the caller passes the real hash.
//
// Every problem is reported, not just the first, as { code, message, path },
// in the same shape as validateEditTimeline.
// ---------------------------------------------------------------------------

import Ajv2020 from "ajv/dist/2020.js";
import addFormats from "ajv-formats";
import schema from "../schemas/v1alpha1/word-timing.schema.json" with { type: "json" };
import { jsonPath } from "./edit-timeline.mjs";

/** A word may start this much before the previous one ends (aligner rounding). */
export const WORD_OVERLAP_TOLERANCE_SECONDS = 0.001;
/** A word or speech span may end this much after the audio does. */
export const DURATION_TOLERANCE_SECONDS = 0.05;
/** The energy envelope may be this many samples longer or shorter than the audio. */
export const ENERGY_LENGTH_TOLERANCE_SAMPLES = 1;

let compiled = null;

function schemaValidator() {
  if (!compiled) {
    const ajv = new Ajv2020({ allErrors: true, strict: true });
    addFormats(ajv);
    ajv.addSchema(schema);
    compiled = ajv.getSchema(`${schema.$id}#/$defs/WordTiming`);
  }
  return compiled;
}

function issue(code, path, message) {
  return { code, message, path };
}

const collapse = (text) => text.trim().split(/\s+/).join(" ");

/**
 * Validate a WordTiming document.
 * @param {unknown} doc
 * @param {{audioHash?: string}} [options] the real hash of the audio file, when the caller has it
 * @returns {{code: string, message: string, path: string}[]} every problem; empty when valid.
 */
export function validateWordTiming(doc, { audioHash } = {}) {
  const validate = schemaValidator();
  if (!validate(doc)) {
    return validate.errors.map((e) =>
      issue("schema", jsonPath(e.instancePath), `${e.instancePath || "/"} ${e.message}`),
    );
  }
  return [
    ...checkAudio(doc, audioHash),
    ...checkWords(doc),
    ...checkText(doc),
    ...checkLines(doc),
    ...checkSpeech(doc),
    ...checkEnergy(doc),
  ];
}

function checkAudio(doc, audioHash) {
  if (audioHash === undefined || audioHash === doc.audio.hash) return [];
  return [issue("audio-mismatch", "$.audio.hash", `timing was made for ${doc.audio.hash}, but the audio is ${audioHash}`)];
}

function checkWords(doc) {
  const out = [];
  const limit = doc.audio.durationSeconds + DURATION_TOLERANCE_SECONDS;
  doc.words.forEach((w, i) => {
    const p = `$.words[${i}]`;
    if (w.end < w.start) {
      out.push(issue("word-order", `${p}.end`, `word "${w.text}" ends at ${w.end}, before it starts at ${w.start}`));
    }
    const previous = doc.words[i - 1];
    if (previous && w.start < previous.end - WORD_OVERLAP_TOLERANCE_SECONDS) {
      out.push(issue("word-order", `${p}.start`, `word "${w.text}" starts at ${w.start}, before "${previous.text}" ends at ${previous.end}`));
    }
    if (w.end > limit) {
      out.push(issue("out-of-range", `${p}.end`, `word "${w.text}" ends at ${w.end}, after the audio ends at ${doc.audio.durationSeconds}`));
    }
  });
  return out;
}

function checkText(doc) {
  const joined = doc.words.map((w) => w.text).join(" ");
  if (joined === collapse(doc.text)) return [];
  const words = joined.split(" ");
  const text = collapse(doc.text).split(" ");
  const at = words.findIndex((w, i) => w !== text[i]);
  const where = at === -1 ? words.length : at;
  return [issue("text-mismatch", `$.words[${Math.min(where, doc.words.length - 1)}].text`,
    `the words differ from text at word ${where}: "${words[where] ?? "(none)"}" vs "${text[where] ?? "(none)"}"`)];
}

function checkLines(doc) {
  const out = [];
  let previousLast = -1;
  (doc.lines ?? []).forEach((line, i) => {
    const p = `$.lines[${i}]`;
    if (line.firstWord > line.lastWord) {
      out.push(issue("bad-line", `${p}.lastWord`, `line "${line.id}" ends at word ${line.lastWord}, before it starts at ${line.firstWord}`));
    }
    if (line.lastWord >= doc.words.length) {
      out.push(issue("bad-line", `${p}.lastWord`, `line "${line.id}" names word ${line.lastWord}, but there are ${doc.words.length} words`));
    }
    if (line.firstWord <= previousLast) {
      out.push(issue("bad-line", `${p}.firstWord`, `line "${line.id}" starts at word ${line.firstWord}, inside the previous line (ends at ${previousLast})`));
    }
    previousLast = Math.max(previousLast, line.lastWord);
  });
  return out;
}

function checkSpeech(doc) {
  const out = [];
  const limit = doc.audio.durationSeconds + DURATION_TOLERANCE_SECONDS;
  let previousEnd = -Infinity;
  (doc.speech ?? []).forEach(([start, end], i) => {
    const p = `$.speech[${i}]`;
    if (start >= end) out.push(issue("speech-order", p, `speech span ${start}–${end} is empty or reversed`));
    if (start < previousEnd) out.push(issue("speech-order", `${p}[0]`, `speech span starts at ${start}, before the previous one ends at ${previousEnd}`));
    if (end > limit) out.push(issue("out-of-range", `${p}[1]`, `speech span ends at ${end}, after the audio ends at ${doc.audio.durationSeconds}`));
    previousEnd = Math.max(previousEnd, end);
  });
  return out;
}

function checkEnergy(doc) {
  if (!doc.energy) return [];
  const expected = Math.round(doc.audio.durationSeconds * doc.energy.rate);
  const actual = doc.energy.values.length;
  if (Math.abs(actual - expected) <= ENERGY_LENGTH_TOLERANCE_SAMPLES) return [];
  return [issue("energy-length", "$.energy.values",
    `${actual} energy samples at ${doc.energy.rate}/s, but ${doc.audio.durationSeconds} s of audio needs about ${expected}`)];
}

/**
 * Start, end and text of one line, derived from its words.
 * @returns {{id: string, start: number, end: number, text: string, speaker?: string}}
 */
export function lineSpan(doc, index) {
  const line = doc.lines?.[index];
  if (!line) throw new RangeError(`no line at index ${index}`);
  const words = doc.words.slice(line.firstWord, line.lastWord + 1);
  return {
    id: line.id,
    start: words[0].start,
    end: words[words.length - 1].end,
    text: words.map((w) => w.text).join(" "),
    ...(line.speaker === undefined ? {} : { speaker: line.speaker }),
  };
}
```

```ts
  | "bad-line"
  | "speech-order"
  | "energy-length";

  path: string;

  speaker?: string;
```

```js
#!/usr/bin/env node

/**
 * Validate word-timing fixtures: every valid fixture has no problem; every
 * invalid fixture (a valid base plus a patch) fails with exactly its code.
 * Usage: node scripts/check-word-timing-fixtures.mjs
 */

import { readFileSync, readdirSync } from "node:fs";
import { fileURLToPath } from "node:url";
import { dirname, resolve } from "node:path";
import { validateWordTiming } from "../src/word-timing.mjs";
import { applyPatch } from "./lib/json-patch.mjs";

const root = resolve(dirname(fileURLToPath(import.meta.url)), "..");
const dir = resolve(root, "fixtures/word-timing");
const readJson = (path) => JSON.parse(readFileSync(path, "utf-8"));
const valid = readdirSync(resolve(dir, "valid")).filter((f) => f.endsWith(".json"));
const invalid = readdirSync(resolve(dir, "invalid")).filter((f) => f.endsWith(".json"));

let failures = 0;

for (const file of valid) {
  const problems = validateWordTiming(readJson(resolve(dir, "valid", file)));
  if (problems.length > 0) {
    failures += 1;
    console.error(`FAIL valid ${file}:`, problems.map((p) => `${p.code} ${p.path}`).join("; "));
  } else {
    console.log(`PASS valid ${file}`);
  }
}

for (const file of invalid) {
  const fixture = readJson(resolve(dir, "invalid", file));
  const doc = applyPatch(readJson(resolve(dir, "valid", fixture.base)), fixture.patch);
  const found = [...new Set(validateWordTiming(doc).map((p) => p.code))];
  if (found.length !== 1 || found[0] !== fixture.expect) {
    failures += 1;
    console.error(`FAIL invalid ${file}: expected [${fixture.expect}], got [${found.join(", ")}]`);
  } else {
    console.log(`PASS invalid ${file} rejected with ${fixture.expect}`);
  }
}

if (failures) {
  console.error(`\n${failures} word-timing check(s) failed`);
  process.exitCode = 1;
} else {
  console.log(`\n${valid.length} valid and ${invalid.length} invalid word-timing fixtures passed`);
}
```
