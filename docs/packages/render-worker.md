# render-worker

> Renders a remotion-composer edit timeline on other machines over SSH, or shares its one-second segments among several: code by git push, files by content hash, the video back, checked. Optional at run time: without a host, a render stays on this machine.

## Using it outside this project

This is a reusable tool. It does not know what an episode, a series or a
pipeline is, and it must never learn — `npm run check:boundaries` fails if
it grows a dependency on `studio/*`. Studio-specific integration lives in
[`studio/agent`](../studio/agent.md).
